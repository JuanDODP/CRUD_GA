① Modelo de Dominio

Entidades principales del sistema y sus relaciones de asociación, composición y dependencia. Muestra la jerarquía de datos desde la autenticación hasta la gestión de asignaciones entre usuarios y proyectos, incluyendo el enum Rol y el tipo de estado AuthStatus.

«entity» Entidad de Dominio
«interface» Interfaz TypeScript
«enum» / «type» Tipo Escalar
──▶ Asociación (navega hacia)
- - ▶ Dependencia (usa)

② DTOs e Interfaces de API

Objetos de transferencia de datos para las respuestas de la API REST. Incluye interfaces de respuesta para cada recurso, interfaces de vistas especializadas para el Tablero Kanban (TableroItem, TeamMember) y el Calendario Gantt (ProyectoBar, TimelineRow, MonthSegment).

«interface» — todos los DTOs son interfaces TypeScript
«type» — union type escalar

③ Servicios Angular — Capa de Datos

Servicios inyectables (@Injectable({providedIn:'root'})) con estado reactivo via Angular Signals. Gestionan operaciones CRUD contra la API REST, mantienen el estado global de las colecciones de datos y coordinan dependencias entre sí para mantener la consistencia del estado de la UI.

«@Injectable» Servicio Angular
Dependencia Externa
- -▶ injects → Inyección de dependencia entre servicios
- -▷ dep → Dependencia técnica (HttpClient, environment)

④ Componentes de Página (Smart Components)

Componentes de alto nivel con lógica de negocio: inyectan servicios, gestionan estado local con signal() y computed(), y exponen datos procesados a los componentes hijos. Todos implementan ChangeDetectionStrategy.OnPush para máximo rendimiento.

«page component» — Componente de Página
attrs = servicios inyectados + signals de estado local
methods = computed signals + handlers de eventos

⑤ Componentes Compartidos (Presentational)

Componentes reutilizables sin lógica de negocio propia, agrupados por módulo funcional. Reciben datos mediante signal inputs (input.required<T>()) y emiten eventos mediante outputs (output<T>()). Implementan ChangeDetectionStrategy.OnPush.

«shared component» — Componente Presentacional
attrs = signal inputs del componente
methods = outputs + métodos de renderizado

⑥ Seguridad y Enrutamiento

Guards de autenticación (CanActivateFn / CanMatchFn), interceptores HTTP para agregar el token JWT a cada petición, y la configuración completa de rutas con lazy loading de componentes. El guard maneja el estado SSR y la espera asíncrona del estado 'checking'.

«guard» — Función de Guarda de Ruta
«interceptor» — Interceptor HTTP funcional
Configuración de Rutas / ApplicationConfig
